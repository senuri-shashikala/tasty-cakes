A responsive cake shop website built with HTML, CSS, and JavaScript where visitors can browse cakes by category, check prices, and view ordering details.

> Note: This is a practice project created during my web development learning journey. It is not a commercial storefront, and the contact details used are sample placeholders.

---

## Live Demo

View the deployed project here: [https://senuri-shashikala.github.io/tasty-cakes/](https://senuri-shashikala.github.io/tasty-cakes/)

---

## Key Features

- Cake Gallery: Showcases 5 cake items with photos and pricing.
- Category Filtering: Interactive category filter (All, Birthday, Wedding, Brownies, and more) powered by JavaScript.
- Price Table: Structured price list for easy comparison.
- Ordering & Value Sections: Includes a step-by-step ordering guide (ordered list) and key highlights (unordered list).
- Time-Based Delivery Notice: Dynamically updates the same-day delivery message after 4:00 PM.
- Hero Animation: Subtle CSS animation applied to the hero image.
- Responsive Design: Adapts smoothly across desktop, tablet, and mobile viewports.
- Navigation & Contact Links: Includes internal navigation along with email and social links.

## Responsive Breakpoints

| Screen Width | Layout Behaviour |
| :--- | :--- |
| Desktop / Laptop (> 900px) | 5-column cake grid |
| Tablet (≤ 900px) | 3-column cake grid |
| Mobile (≤ 600px) | 2-column cake grid |

## Running Locally

No build tools or package installations are required:

1. Clone or download the repository:

    git clone https://github.com/senuri-shashikala/tasty-cakes.git

2. Open index.html directly in your web browser (or run it via a local development server such as VS Code Live Server).
